# 🪔 Secret Diwali — Festive Gift Exchange Web App

A festive, mobile-friendly gift exchange game customized for Diwali family gatherings, office parties, and friends groups.

## ✨ Key Features

- **Mobile-First Experience**: Designed with smooth touch gestures, festive Diwali gold, marigold orange, and midnight purple aesthetics.
- **Pass-the-Phone Reveal**:
  - Privacy blind with countdown to ensure only the intended person peeks.
  - Interactive touch-to-light clay diya with authentic flame flicker animation.
  - Realistic 3D card flip reveal.
- **Fair Pairing Engine**:
  - Balanced derangement algorithm ensuring nobody draws themselves.
  - Customizable exclusion rules (e.g., prevent spouses or siblings from drawing each other).
- **Remote Sharing**:
  - Encrypted/Base64 URL hash tokens (`#reveal=TOKEN`) for friends or family members who cannot attend in person.
  - 1-click WhatsApp share links with pre-formatted festive messages.
- **Synthesized Web Audio API**:
  - Diya ignition crackle, temple bell chimes, and celebration fanfares generated entirely via native browser audio (no external audio assets required).
- **Master Report & Match Storage**:
  - Comprehensive organizer dashboard to view and cross-verify all gift pairings in one place.
  - Live search and filter by participant name with privacy mask mode.
  - Store multiple draw snapshots in local history to review or restore anytime.
  - 1-click Export to CSV (Excel/Sheets) and JSON backup files.
  - Print-friendly layout and formatted text report for WhatsApp/Email.
- **Host Controls & Audit**:
  - Full derangement verification ensuring nobody draws themselves and all exclusion rules are respected.
  - Budget, currency (₹, $, £, €), exchange date, and event venue customization.

## 🚀 How to Run

1. Simply double-click `index.html` to open it in any modern web browser (Chrome, Safari, Firefox, Edge).
2. No Node.js, build step, or web server is strictly required. Everything is bundled into a self-contained file with CDN scripts for Tailwind CSS and confetti.

## 🌐 Deploying Online

You can host this for free on:
- **GitHub Pages**: Push this repo to GitHub, go to Settings → Pages, and select the main branch.
- **Netlify / Vercel**: Drag and drop this folder onto Netlify Drop or Vercel.
